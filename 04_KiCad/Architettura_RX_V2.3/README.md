# Architettura RF V2.3 - ancora NON uno schema KiCad

Il progetto V2.3 non genera simboli/netlist/PCB di ricezione. Aggiunge un confronto numerico di due possibili posizioni dei filtri e di due amplificatori SMD. Realizzare lo schema senza modelli S-parameter di filtri e switch avrebbe dato una falsa impressione di maturità del progetto.

Rinvio: `01_Specifiche/Studio_Catena_RX_V2.3.md`, `03_Verifiche/V2.3`.
